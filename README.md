# OBS-Reloj

Plugin Lua para OBS Studio que permite mostrar un reloj personalizado con fecha y hora en tiempo real.

## Características

- Mostrar hora actual.
- Mostrar fecha.
- Personalización visual.
- Integración con OBS Studio mediante Lua.

## Instalación

1. Descarga el archivo `reloj_pro.lua`.
2. Abre OBS Studio.
3. Ve a **Herramientas → Scripts**.
4. Pulsa el botón `+`.
5. Selecciona el archivo `reloj_pro.lua`.
6. Configura el plugin según tus preferencias.
